# Rum River Wedding Barn

Wedding venue website built with React + Vite.

## Quick Start

```bash
npm install
npm run dev          # Development server
npm run build        # Production build
```

## Design Tokens

Edit colors/fonts/spacing in `/tokens/*.json`, then run:

```bash
npm run tokens:build
```

See [DESIGN_TOKENS.md](DESIGN_TOKENS.md) and [SIMPLE_MIGRATION.md](SIMPLE_MIGRATION.md) for details.
